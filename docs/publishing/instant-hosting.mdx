# Instant Hosting

Gone are the days of renting dedicated servers, configuring port forwarding, and troubleshooting firewall rules. HELIX's **Instant Hosting** lets you deploy a multiplayer server with a single click -- your world goes live in seconds.

## How It Works

When you deploy from **Creator Hub** or **HELIX Studio**, the platform spins up a dedicated server pre-configured with your world's settings, packages, and map. Players can connect immediately through the HELIX client -- no IP addresses or port numbers needed.

Behind the scenes, HELIX handles:

- **Server provisioning** -- Your instance is deployed on infrastructure optimized for game workloads.
- **Networking** -- Automatic port allocation, DDoS protection, and low-latency routing.
- **Updates** -- When you publish a new version of your world, running servers can pick up changes without manual intervention.

## Configuring Your Server

Before hosting, you can adjust settings through Creator Hub:

- **Max players** -- Set the player cap for your world (affects resource allocation).
- **Region** -- Choose a geographic region to minimize latency for your target audience.
- **Game mode** -- Select which game mode package to load at startup.
- **Server name and description** -- What players see in the server browser.
- **Access control** -- Make your world public, private (invite-only), or friends-only.

These settings are saved to your world configuration, so you don't need to reconfigure every time you host.

## Scaling (Upcoming)

As your world grows in popularity, upcoming features will help you scale:

- **Upgraded resource profiles** -- Upgrade CPU and RAM for more demanding worlds.
- **Elastic scaling** -- Automatic horizontal scaling for large events.
- **Database scaling** -- Scale databases for more active players.

These scaling features are currently in development and will be available in future updates.

## Replacing Self-Hosted Servers

If you've been running your own dedicated servers, Instant Hosting is designed to replace that workflow entirely. You get better uptime, zero maintenance, and the HELIX platform handles operating system updates, crash recovery, and restarts automatically.

Your world's server-side scripts, packages, and configuration all work the same way -- the only difference is you're no longer managing the hardware yourself.

## Pricing

Instant Hosting is billed using **LIX**, the platform currency. You can choose **Daily**, **Weekly**, or **Monthly** renewal cycles, and LIX is automatically deducted at each interval. If your balance runs out, you enter a **48-hour grace period** where your server stays online. If still unpaid after 48 hours, the server is safely shut down.

Every Instant Hosting server also includes its own **dedicated database**, automatically provisioned on deployment with no extra configuration required.
