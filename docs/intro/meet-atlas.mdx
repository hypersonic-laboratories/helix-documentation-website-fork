# Meet Atlas

Atlas is your AI-powered documentation companion. Think of Atlas as a teammate who has read every page of these docs, every API reference, and every tutorial — and is happy to answer questions at 3 AM.

## What Atlas can do

- **Answer questions** about HELIX, from basic concepts to advanced scripting
- **Generate code examples** in Blueprints, Lua, or JavaScript
- **Point you to the right docs page** when you're lost
- **Debug your scripts** by explaining error messages and suggesting fixes
- **Explain architecture** decisions and best practices

## How to use Atlas

You'll find Atlas available throughout the documentation. Ask it anything:

- *"How do I spawn a vehicle in Lua?"*
- *"What's the difference between a World and a Package?"*
- *"Show me how to set up a basic inventory system"*
- *"Why is my Blueprint not replicating to clients?"*

Atlas understands context. If you're on a specific docs page and ask a follow-up question, Atlas knows what you've been reading.

## Atlas is not a replacement for the docs

Atlas is great at quick answers and code snippets. But for deep understanding — the kind that makes you a great HELIX creator — read the full guides. Atlas will tell you the same thing.

## Get started

Try asking Atlas something right now. No question is too basic. Everyone starts somewhere, and Atlas has infinite patience.

Go build something awesome. Atlas will be here whenever you need a hand.
