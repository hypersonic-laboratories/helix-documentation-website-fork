# How It Works

Think of HELIX like a music streaming service — but for multiplayer game worlds. Creators make the content, the platform handles distribution and hosting, and players drop in to enjoy it.

Here's how the pieces fit together.

## Worlds

A **World** is a playable multiplayer experience. It could be an RP server, a racing game, a survival sandbox, or anything you dream up. Worlds are what players browse and join from the HELIX client.

Every World is built from one or more **Packages**.

## Packages

A **Package** is a self-contained bundle of content — maps, scripts, assets, game modes, UI elements. Packages are the building blocks of Worlds. You can create your own or grab them from Vault.

Want a vehicle system? There's a Package for that. Need a weather script? Grab one. Packages snap together like LEGO bricks.

## Vault

The **Vault** is where Packages live. It's part repository, part marketplace. You can:

- **Browse** community-made Packages
- **Download** free assets and scripts
- **Sell** your own creations for LIX
- **Update** Packages and push changes to every World using them

Think npm meets the Steam Workshop, with a built-in economy.

## HELIX Studio

**HELIX Studio** is a customized Unreal Engine 5 Editor — your full creative toolkit. This is where you build maps, create Blueprints, design UI, and develop Packages. If you've used UE5 before, you're already home. If you haven't, it's more approachable than you'd expect.

HELIX Studio replaced the older "Creator Kit" and ships through the HELIX Launcher.

## Instant Hosting

When your World is ready, you don't need to wrestle with dedicated servers. **Instant Hosting** deploys your World to the HELIX network with a single click. Scaling, uptime, networking — all handled.

## Build Mode

Already in-game and want to tweak things? Press **N** to enter **Build Mode** — a real-time in-world editor for placing objects, adjusting properties, and testing on the fly. Build Mode is great for quick edits and prototyping directly in your World, while HELIX Studio is where you create Packages with custom assets, Blueprints, and more polished content.

## The Flow

1. **Create** a World from the HELIX client
2. **Build** Packages in HELIX Studio or place objects in Build Mode
3. **Publish** to Vault
4. **Host** with Instant Hosting
5. **Earn** LIX when players join and engage

That's the loop. Build, ship, earn, repeat.
