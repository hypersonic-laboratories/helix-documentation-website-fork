:::tip[What you'll build]

A custom-made character (or one imported from Fab/Mixamo/Meshy) that
walks, runs, and shows up correctly in multiplayer. By the end you'll
have replaced the default skin with your own.

:::

## Steps in this tutorial

1. **Pick a source** — model from scratch, import from Fab, or AI-generate via Meshy
2. **Rig & set up bones** — Unreal's standard humanoid skeleton
3. **Default animations** — wire up walk / run / idle
4. **Materials & textures** — apply HELIX's default character material setup
5. **Test in Build Mode** — preview how it looks in-game
6. **Network it** — make sure other players see your character correctly

:::info[Before you start]

- Either a 3D-modelling tool (Blender free, or paid options like Maya), or a Fab account
- The "Create Your First Experience" tutorial completed (recommended)
- Familiarity with HELIX's character system — see *Game Systems → Characters*

:::

:::note[Naming note for the team]

"Avatar" is Kostas's prototype copy; HELIX uses "Character" elsewhere
in the docs. Worth deciding on consistent terminology in the content pass.

:::
