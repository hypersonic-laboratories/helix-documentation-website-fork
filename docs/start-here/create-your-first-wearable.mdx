:::tip[What you'll build]

A wearable item (jacket, hat, chain, glasses — your choice) that fits
your character correctly, supports the default HELIX clothing materials,
and is testable in Build Mode.

:::

## Steps in this tutorial

1. **Design or import the mesh** — Blender, Marvelous Designer, or Fab
2. **Skin it to the character rig** — bind the cloth to the body bones
3. **Apply default clothing materials** — use HELIX's PBR material library
4. **Set up attachment points** — for accessories like hats or chains
5. **Test in Build Mode** — equip / unequip cycle on a test character
6. **Package & publish** — ready it for the Vault

:::info[Before you start]

- A 3D tool that can export FBX (Blender works great and is free)
- Optional but recommended: Marvelous Designer for cloth simulation
- The "Create Your First Avatar" tutorial completed, so you have a character to test against

:::
