# Vehicles

HELIX uses the [`HVehicle`](/api/classes/vehicle) class to handle all drivable vehicles -- cars, trucks, boats, you name it. The system handles physics, engine simulation, fuel, and lighting so you can focus on building great driving experiences.

## Spawning a Vehicle

Drop a vehicle into your world by creating a new [`HVehicle`](/api/classes/vehicle) instance with a position, rotation, and Blueprint asset reference.

<Tabs groupId="scripting-language">
<TabItem value="blueprint" label="Blueprint" default>

<BlueprintGraph
  title="Spawn a vehicle at a location"
  nodes={[
    { id:'bp', title:'Event BeginPlay', style:'event', x:30, y:30, pins:[
      {id:'eo',label:'',type:'exec',side:'output'}
    ]},
    { id:'spawn', title:'Spawn HVehicle', style:'function', x:300, y:30, pins:[
      {id:'ei',label:'',type:'exec',side:'input'},
      {id:'eo',label:'',type:'exec',side:'output'},

      {id:'rot',label:'Rotation',type:'rotator',side:'input',value:'(0, 90, 0)'},
      {id:'asset',label:'Asset',type:'string',side:'input',value:'"BP_Sedan"'},
      {id:'ret',label:'Vehicle',type:'object',side:'output'}
    ]}
  ]}
  wires={[
    {from:{node:'bp',pin:'eo'},to:{node:'spawn',pin:'ei'}}
  ]}
/>

</TabItem>
<TabItem value="lua" label="Lua">

```lua
-- Spawn a vehicle at a specific location
local my_car = HVehicle(
    Vector(1000, 0, 50),
    Rotator(0, 90, 0),
    "/Game/Vehicles/BP_Sedan.BP_Sedan_C"
)
```

</TabItem>
<TabItem value="js" label="JavaScript">

```javascript
// Spawn a vehicle at a specific location
const myCar = new HVehicle(
    new Vector(1000, 0, 50),
    new Rotator(0, 90, 0),
    "/Game/Vehicles/BP_Sedan.BP_Sedan_C"
);
```

</TabItem>
</Tabs>

<TabItem value="lua" label="Lua">

```lua
-- Apply full throttle and steer left
my_car:SetThrottleInput(1.0)
my_car:SetSteeringInput(-0.5)

-- Apply brakes
my_car:SetBrakeInput(1.0)

-- Engage handbrake
my_car:SetHandBrakeInput(true)
```

</TabItem>
<TabItem value="js" label="JavaScript">

```javascript
// Apply full throttle and steer left
myCar.SetThrottleInput(1.0);
myCar.SetSteeringInput(-0.5);

// Apply brakes
myCar.SetBrakeInput(1.0);

// Engage handbrake
myCar.SetHandBrakeInput(true);
```

</TabItem>
</Tabs>

Steering input ranges from `-1.0` (full left) to `1.0` (full right). Throttle and brake range from `0.0` to `1.0`.
