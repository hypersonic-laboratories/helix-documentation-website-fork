# Publish & Play

You've built a World. You've scripted it. Now let's put it in front of real people.

## Publish your Package to Vault

The **Vault** is HELIX's centralized package repository and marketplace. Every Package you want to share — scripts, assets, full game modes — gets published here.

If you created custom Packages in **HELIX Studio**, you can publish them from the Package properties dialog — select your Package, open the publishing options, and publish to Vault. Both the Package and its dependencies can be published together.

If you built your World using **Build Mode**, press the **Publish button** (rocket icon) in the Build Mode toolbar. This zips up your local workspace and uploads it to Vault.

Set the visibility to **Public** (everyone can find it) or **Private** (invite-only — you can grant access to specific users from Creator Hub).

Your content is now live on Vault. Other creators can discover it, download it, and use it in their own Worlds.

## Set up Instant Hosting

Here's where the magic happens. No server rental, no port forwarding, no Linux sysadmin skills required.

**Instant Hosting** deploys your World to a dedicated server with a single click from **Creator Hub**. You get a dedicated server instance, a dedicated database, and fully managed infrastructure — all billed in LIX.

Once deployed, your World shows up in the server browser for players to connect immediately.

:::tip
Instant Hosting handles scaling, uptime, and updates automatically. If you've been renting VPS boxes to run game servers, those days are over. You can still host dedicated servers yourself if you prefer — see the dedicated server guide.
:::

## Invite friends

Once your World is live:

- Share the **World link** directly — friends can click it to join
- Or tell them to search for your World name in the **World browser** inside the HELIX client

They'll connect, load in, and experience everything you built.

## Watch it come alive

Open your World and walk around alongside your friends. Everything you built — objects placed in Build Mode, Packages created in HELIX Studio, every script you wrote — it's all running live in multiplayer. This is the payoff.

## Start earning with LIX

Here's a teaser: once your World has players, you can start monetizing. **LIX** is the HELIX platform currency, and players spend it on in-world purchases and premium content. Creators earn LIX through their Worlds and Vault sales, and earned LIX can be converted to real money through creator payouts.

We'll cover monetization in depth in the [Monetization Guide](/docs/publishing/monetization). For now, focus on making something people want to play.
