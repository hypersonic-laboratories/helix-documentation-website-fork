# Install HELIX

Let's get you set up. The whole process takes about 10 minutes depending on your internet speed.

## Step 1: Create your account

Head to **[helixgame.com](https://helixgame.com)** and create a free HELIX account. You'll need a valid email address. This account is your identity across the entire platform — client, studio, Vault, everything.

## Step 2: Download the Launcher

After signing in, download the **HELIX Launcher** for your platform. The Launcher is your central hub for installing and updating everything HELIX-related.

## Step 3: Install HELIX Client + HELIX Studio

Open the Launcher and you'll see two main products:

- **HELIX (Client)** — This is what you use to play, browse Worlds, and join servers
- **HELIX Studio** — A customized Unreal Engine 5 Editor for building Worlds and Packages

Install both. HELIX Studio is where you'll do your creative work, and the Client is where you'll test and play.

:::info
HELIX Studio replaced the older "Creator Kit." If you see references to Creator Kit in community posts, they're talking about HELIX Studio.
:::

## System Requirements

HELIX is built on Unreal Engine 5, so you'll need a machine that can handle modern UE5 content. A dedicated GPU, 16 GB of RAM, and an SSD are strongly recommended for a smooth experience — loading UE5 worlds from a spinning hard drive is a painful experience.

:::info
Official system requirements will be published as HELIX approaches general availability. For now, if your machine runs UE5 projects well, you're in good shape.
:::

## Verify the install

Launch HELIX from the Launcher. If you see the main menu and can browse Worlds, you're golden. Open HELIX Studio from the Launcher and confirm it loads the Unreal Editor interface.

You're ready to create. Let's build your **[first World](/docs/getting-started/your-first-world)**.
